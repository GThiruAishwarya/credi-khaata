 CreditKhaata - Loan Ledger UI for Shopkeepers

A responsive credit tracking web app built with React.js for small shopkeepers to manage trusted customers, track credit sales, record repayments, and view dues from a single dashboard.



🔗 Deployed Link

[View Live App](https://creditKhaata.vercel.app)  



 Features

Login/Signup with email & password (mock authentication)
Dashboard view of all customers with outstanding balances, last transaction dates, and overdue indicators
Customer Details with loan items, repayments, and remaining balances
Add New Customer with form validation
Overdue Highlighting for late payments



Tech Stack

Frontend: React.js (with Hooks and Context API)
Styling: Tailwind CSS
State Management: useState, useContext
Form Handling: react-hook-form
Routing: react-router-dom
